Smart Door Lock — Double Authentication

Sistem pengamanan pintu cerdas dengan double authentication menggunakan ESP32-CAM untuk face recognition dan ESP32 DevKit C V4 untuk autentikasi kedua (Keypad/Fingerprint/RFID). Terintegrasi dengan web dashboard real-time melalui Node.js API dan Firebase Realtime Database.

Face recognition sebagai autentikasi pertama
Triple option autentikasi kedua (PIN, Fingerprint, RFID)
Web dashboard real-time dengan SSE live update
REST API untuk manajemen device & akses
ESP32-CAM ESP32 DevKit Python OpenCV Node.js Firebase Express.js
Web Development Full-Stack Real-time

Real-time Monitoring Dashboard

Web dashboard untuk monitoring dan manajemen sistem Smart Door Lock secara real-time. Menampilkan log akses, status perangkat, serta manajemen kartu RFID dan sidik jari dengan desain glassmorphism yang modern.

Dark theme glassmorphism UI
Real-time event streaming (SSE)
CRUD kartu RFID & fingerprint management
HTML/CSS JavaScript Node.js Express.js Firebase SSE
Computer Vision Python AI/ML
